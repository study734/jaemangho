# 멤버의 요구·불편을 받는 경로

상태: 결정 대기
작성: 소유자(2026-11-20 세션 대화) · 정리: 에이전트 · 날짜: 2026-11-20
출처: 2026-11-20 요구사항 점검

## 문제
- 요구사항이 들어오는 경로가 소유자의 세션 대화 하나뿐이다. GitHub 이슈는 지금까지 0건이고, 멤버가 직접 의견을 남길 곳이 없다(확인함).
- 사용 신호는 관리자 "개선 우선순위"의 열람·오류 집계뿐이며, 최근 7일 웹 열람이 0회였던 기록이 있다(#137). 사람들은 디스코드에 있다.
- 결과적으로 무엇을 만들지가 한 사람에게 묶여 있다(AGENTS.md의 "특정 사람에 대한 의존" 병목).

## 원하는 결과
멤버가 디스코드에서 바로 의견·버그를 남기고, 그것이 이 `intent/` 흐름의 입력이 된다. 무엇을 만들지는 여전히 소유자가 정한다.

## 영향 받는 사용자·시스템
디스코드 멤버, `src/server/discord-interactions`, 저장 위치(DB 또는 GitHub 이슈), 관리자.

## 제약
- 개인정보: 의견 원문 저장 범위와 보관 기간을 정해야 한다(지금은 메시지 내용을 저장하지 않는 원칙).
- GitHub 이슈로 보내려면 토큰 환경변수가 새로 필요하다(사전 확인 대상). DB에 저장하고 관리자 화면·`/개선`에서 보면 환경변수가 필요 없다.
- 새 디스코드 명령은 배포 빌드에서 자동 등록된다.
