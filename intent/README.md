# intent: 의도 → 명세 → 계획

새 기능·동작 변경은 이 폴더에서 시작한다. 절차와 사람의 승인 지점은 [AGENTS.md의 AI-native 개발 흐름](../AGENTS.md#ai-native-개발-흐름)이 기준이다.

- 작업마다 `NNNN-영문-요약/` 폴더 하나를 만든다(번호는 이어서 붙인다). 안에 `intent.md` → `spec.md` → `plan.md`를 단계마다 추가해 커밋한다. 양식은 [`_template/`](_template/)에 있다.
- 각 파일 맨 위의 `상태`가 그 단계의 현재 상태다. 따로 목록·보고서를 만들지 않는다. 진행 중인 일은 `rg -l "^상태: (초안|결정 대기|수락|승인)" intent/ -g "!_template"`로 찾는다.
- 구현이 끝난 뒤 지금 동작의 설명은 README·OPERATIONS에 남기고, 이 폴더에는 **왜 그렇게 정했는지**만 남긴다. 같은 내용을 두 곳에 복사하지 않는다.
- 작은 버그 수정과 동작을 바꾸지 않는 정리는 이 폴더 없이 바로 PR로 간다.
