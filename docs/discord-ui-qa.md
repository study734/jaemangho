# Discord 채널 UI 검증

2026-10-10, PR #55 후속 작업. 아래 이미지는 로컬 Chromium의 실제 화면 캡처이며 테스트용 데이터로 확인했다.

## 배치

- PC: 서비스 아이콘 레일 72px, 채널 목록 232px, 가운데 기록 피드, 오른쪽 실행·멤버 열 320px. 피드와 오른쪽 열은 각각 스크롤하며 사용자 패널은 왼쪽 하단에 남는다. 피드에 더 많은 공간을 배분해 발견과 랭크 표의 가독성을 우선했다.
- 1024px 이하: 발견 → 게임 찾기·Steam 검색 → 기록·현황의 한 열. 모바일에서는 기존 상단 바와 하단 네 탭을 유지한다.
- 재망호 색상 토큰, 주요 행동 pill, 입력 8px, 카드 12px을 유지한다. 새 채팅·온라인 상태·기능 없는 도구 버튼은 추가하지 않는다.

## 실제 화면과 흐름

- `output/playwright/discord-desktop.png`, `discord-tablet.png`, `discord-mobile.png`: 1504px·1024px·390px의 빈 홈.
- `output/playwright/discovery-content-1504.png`, `discovery-content-1024.png`, `discovery-content-390.png`: 선별된 기록과 결과 공개. `discovery-comparison-mobile.png`: 실제 테스트 집계의 비교 막대.
- `output/playwright/home-option1-populated.png`, `home-visual-data.png`: 소환사 네 명, 랭크 표, 디스코드 집계와 최근 접속 멤버.
- 긴 이름과 이미지 실패를 1504·1024·390·320px에서 확인했다. 전체 페이지의 가로 넘침이 없고 표만 필요한 경우 내부 스크롤한다.
- 발견 공개·접기·이전/다음·키보드·반응 저장/취소·공유 복사·게임 검색 연결·모바일 탐색을 기존 E2E로 검증했다.
- 추가 E2E는 PC의 독립 스크롤·빠른 채널 이동과 친구 목록의 이미지 실패·긴 이름·프로필 이동을 검증한다.

## 검사와 한계

- `npm run lint`, `npm test` 기본 실행, `npm run build` 통과. 기본 테스트는 249개 통과, DB가 필요한 93개는 건너뛴다.
- DB 통합 테스트를 실행했으나 임시 DB 생성 권한이 없어 실패했다. 기존 로컬 DB 클러스터의 권한 확대는 자동 승인 검토가 거절하여 변경하지 않았다. 이 실패는 UI 코드의 assertion 실패가 아니며 DB 통합 테스트 통과로 보고하지 않는다.
- 기존 전체 E2E 58개와 별도로 실행한 새 E2E 두 개 모두 통과했다. 로컬 격리 DB에 기존 마이그레이션을 적용하고 기존 권한으로 E2E를 실행했다.
- 네이티브 공유 창, 실제 기기의 손가락 스와이프, 실제 멤버 사진과 운영 데이터 화면은 이번 확인에 포함하지 않는다. 로그인·권한·마이그레이션 파일·배포 설정·환경변수 정의는 변경하지 않았다.
